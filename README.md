## 快速开始

1. 下载对应科目的 `.html` 文件；
2. 用 Chrome、Edge 或 Firefox 双击打开；
3. 进度、草稿、错题和收藏自动存在当前浏览器，不上传服务器。

> 记录只存在本机浏览器。换电脑、换浏览器或清理站点数据后不会自动同步。

## 每个学习中心包含什么

- **知识讲解**：按章节和小节阅读，公式、表格、例题解析在页面内展开。
- **引导式教学**：一次只问一步，先写自己的判断，再对照参考；写不出来可以“讲这一步”。
- **两个独立题库**：客观题（选择 / 判断 / 填空）与大题（卷面作答），共用章节、收藏、错题和进度。
- **逐空反馈**：填空题按空核对，支持常用单位与同义表述；大题按评分点逐项自评，不用关键词冒充批阅。
- **入门诊断与随堂练习**：3 题诊断判断下一步从哪章开始，随堂练习按章抽题。
- **模拟考试**：按章组卷，客观题自动判分，大题交卷后按评分点自评，限时结束自动交卷。
- **错题与复习**：错因分为概念 / 选式 / 单位 / 运算 / 表述；答对后按 1、3、7、15 天安排复测。
- **学习报告**：正确率、分章进度、错因分布、考试记录、项目与闯关记录，可导出 Markdown。
- **学习工具**：知识图谱、资料库、笔记、课件提纲、闪卡、收藏夹、学习路径。
- **PCB 工程实验室**（嘉立创 EDA）：载流线宽、过孔载流、走线压降、电源线压降、微带阻抗、拼板利用率、单位换算、板厂工艺核对，共 8 个估算工具。
- **移动端**：窄屏双列入口、抽屉目录、长表格横向滚动或转为卡片。

## 适用边界

- 题库与解析用于复习自测，不保证覆盖全部考纲，也不替代教材与教师答疑。
- EDA 实验室的线宽、过孔、阻抗、拼板和工艺数值为工程估算，投板前请以板厂最新工艺能力表和实测为准。
- 模拟考试与自评分数只用于自查，不等同于正式成绩。
